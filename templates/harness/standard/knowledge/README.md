# Project Knowledge

> 项目知识库——AI 在本项目工作时的可信知识来源。
>
> AI 应优先查阅此处知识，而非猜测或从代码推断。

---

## 知识索引

| 文档 | 内容 | 使用场景 |
|------|------|---------|
| `架构.md` | 系统架构、模块划分、依赖关系 | 理解整体设计 |
| `业务流程.md` | 核心业务流程、状态机 | 理解业务逻辑 |
| `数据模型.md` | 核心表结构、ER 关系 | 数据库相关开发 |
| `领域术语.md` | 业务术语解释 | 理解需求文档 |
| `接口协议.md` | 对外 API、内部 RPC | 接口开发 |

---

## 加载策略

知识文档属于 **L3 按需查询层**——AI 根据任务自主查阅，不主动预加载。

详见 `context/layers.yaml` 的 L3 配置。

---

## 维护原则

1. **人工确认**——AI 扫描生成的知识必须经人工确认
2. **保持更新**——架构变更时同步更新知识文档
3. **不存代码**——知识文档描述设计，不存放代码示例（代码在仓库）
4. **不存规则**——规则放 `rules/`，不放此处
