## 一、审计方法与可复现口径

### 1.1 工具与环境
记录审计所用工具、扫描脚本、检索方式与源码检出状态。

### 1.2 检查轮次
按实际执行顺序列出（示例：结构扫描 → 逐条核验 → 覆盖度核对 → 链接与敏感信息检查）。

### 1.3 口径声明（含已知偏差，务必先读）
1. 各项统计数字的**基线时点**（审计执行时）。
2. **审计后若追加或修改了 wiki 内容**，必须声明：追加/修改了哪些文件、增加的行数与字节数、统计数字是否重算及原因。
3. 统计口径定义：文件数 / 行数 / 锚点数 / 条目数分别如何计数。
4. **未纳入统计的范围**：行内 `[待确认]` 标注的数量与未收录原因、非同源引用、未覆盖目录或模块。

## 二、量化结果

### 2.1 规模

### 2.2 锚点解析

`[事实]` / `[推断]` / `[待确认]` 三级标注的分布，以及图表数量与是否有证据支撑。

### 3.1 能力地图自洽性

### 3.2 域文档模板合规

### 3.3 目标产物完整性
