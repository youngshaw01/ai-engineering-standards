# Agent 交接协议

每个阶段 Agent 结束时必须输出以下结构，并同步更新 `STATUS.md`：

## 交接记录
- 阶段/任务 ID：
- 输入文件与 commit：
- 实际读取的源码路径：
- 输出文件：
- 执行过的搜索/统计命令：
- 完成内容：
- 未完成内容与原因：
- `[事实]` 数量（估计即可，但需一致口径）：
- `[推断]` 数量：
- `[待确认]` 数量：
- 覆盖盲区：
- 阶段状态（`未开始` / `进行中` / `通过` / `有条件通过` / `阻塞`）：
- 自检结果（对照 `quality-gates.md` 哪几条已满足）：
- 需要协调 Agent 决策的事项：
- 建议下一步：

## 失败时
- 不要静默跳过失败步骤。
- 写明命令、错误摘要和已经验证的替代方法。
- 不要用猜测替代失败扫描。
- 不要在未通过门槛时将状态改为「通过」；**文件已生成 ≠ 通过**。
- 只在分配范围内修改文件（见 `../workflow/README.md` 写入者表）。
