## Project Templates

复制 [templates/harness/standard/](../templates/harness/standard/) 到项目 `.harness/`：

| 模板 | 用途 |
|------|------|
| `harness.yaml` | 项目画像 + 治理配置 |
| `config/rule-id.yaml` | Rule ID 注册表 |
| `governance/exceptions.yaml` | 已知偏差登记 |
