# 治理模型

> ai-engineering-standards 三层治理架构。

---

## 三层模型

```
Layer 0: ai-engineering-standards/
         Global Standard — 通用安全、编码、Harness 规范
              ↓ inherit
Layer 1: .harness/
         Project Governance — 项目规则、知识、workspace
              ↓ expose
Layer 2: .cursor/.trae/.claude/
         AI Adapter — 纯转换层，无规则权力
```

---

## Rule Resolution Priority

```
1. Project Override (.harness/rules/)     ← 项目规则覆盖一切
2. Global Standard (本仓库章节文档)        ← 通用标准兜底
3. AI Tool Default Rules                  ← 工具默认行为
```

---

## 目录职责分工

| 目录 | Layer | 职责 |
|------|-------|------|
| `11-AI-DevTools/Common-Rules.md` | 0 | L0-L5 公共 AI 约束 |
| `11-AI-DevTools/Harness-Bootstrap.md` | 0 | .harness 规范定义 |
| `.harness/` | 1 | 项目 AI 工作空间（harness.yaml、rules、knowledge、skills、workspace、governance） |
| `.harness/harness.yaml` | 1 | 项目画像与治理配置（唯一入口，禁止 profile.yaml / `.standards/`） |
| `.harness/config/rule-id.yaml` | 1 | Rule ID 注册表 |
| `.harness/governance/exceptions.yaml` | 1 | 老项目已知偏差登记 |
| `.cursor/rules/` | 2 | Adapter，引用 Rule ID |

## Harness 成熟度

| 级别 | 目录 | 接入时间 |
|------|------|---------|
| Bootstrap | AGENTS.md + rules/ + workspace/ | ~5 分钟 |
| Standard | + harness.yaml + knowledge/ + skills/ + context/ + config/ + governance/ | ~30 分钟 |
| Enterprise | + agents/ + mcp/ + audit/ + public/ | ~2 小时 |

详见 `11-AI-DevTools/Harness-Bootstrap.md`。

---

## Skill vs Rule

| 类型 | 问题 | 优先级 |
|------|------|--------|
| Rule | AI 能不能做？ | 高 |
| Skill | AI 会什么？ | 低（不得覆盖 Rule） |
| Knowledge | AI 知道什么？ | 参考 |

Skill 注册表：`.harness/skills/skills.yaml`
