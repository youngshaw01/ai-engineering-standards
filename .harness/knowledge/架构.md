# 仓库架构

> ai-engineering-standards 目录结构与职责。

---

## 顶层结构

```
ai-engineering-standards/
├── 00-Introduction/       ← 接入指南、术语表
├── 01-Engineering/        ← Git、SVN、Code Review、项目结构
├── 02-Java/               ← Java 技术栈规范
├── 03-Python/             ← Python 技术栈规范
├── 04-Frontend/           ← 前端规范
├── 05-Backend/            ← 后端通用规范
├── 06-Architecture/       ← 架构模式
├── 07-AI/                 ← AI 工程规范
├── 08-Testing/            ← 测试规范
├── 09-DevOps/             ← DevOps 规范
├── 10-Product/            ← 产品规范
├── 11-AI-DevTools/        ← AI 工具规则、Harness 规范
├── templates/             ← 可复制模板（profile、Harness 骨架）
├── examples/              ← 代码示例占位
├── .harness/              ← 本仓库 AI 工作空间（Layer 1 实例）
└── .standards/            ← AI 接入声明（profile、rule-id）
```

---

## 章节编号规则

| 前缀 | 含义 |
|------|------|
| `00-` | 入门与索引 |
| `01-10` | 技术领域规范 |
| `11-` | AI 开发与工具 |

每章包含 `README.md` 索引和若干规范文档。

---

## templates/ 职责

| 路径 | 用途 |
|------|------|
| `templates/harness/bootstrap/` | 最小 .harness 模板（5 分钟接入） |
| `templates/harness/standard/` | 标准 .harness 模板（30 分钟接入） |
| `templates/harness/enterprise/` | Enterprise 说明与清单 |
| `templates/project-profile.yaml` | profile.yaml 模板 |
| `templates/rule-id.yaml` | Rule ID 注册表模板 |

---

## 与消费项目的关系

本仓库不包含具体项目规则。消费项目通过以下方式接入：

1. 复制 `templates/harness/` 到项目 `.harness/`
2. 复制 `templates/project-profile.yaml` 到项目 `.standards/profile.yaml`
3. 在 `.cursor/rules/` 等 Adapter 层引用 Rule ID
