# 仓库架构

> ai-engineering-standards 目录结构与职责。

---

## 顶层结构

```
ai-engineering-standards/
├── 00-Introduction/       ← 接入指南、术语表
├── 01-Engineering/        ← Git、SVN、Code Review、项目结构
├── 02-Java/               ← Java 技术栈规范
├── 03-Python/             ← Python 技术栈规范
├── 04-Frontend/           ← 前端规范
├── 05-Backend/            ← 后端通用规范
├── 06-Architecture/       ← 架构模式
├── 07-AI/                 ← AI 工程规范
├── 08-Testing/            ← 测试规范
├── 09-DevOps/             ← DevOps 规范
├── 10-Product/            ← 产品规范
├── 11-AI-DevTools/        ← AI 工具规则、Harness 规范
├── templates/             ← 可复制模板（profile、Harness 骨架）
├── examples/              ← 代码示例占位
├── .harness/              ← 本仓库 AI 工作空间（Layer 1 实例，含 config/）
```

---

## 章节编号规则

| 前缀 | 含义 |
|------|------|
| `00-` | 入门与索引 |
| `01-10` | 技术领域规范 |
| `11-` | AI 开发与工具 |

每章包含 `README.md` 索引和若干规范文档。

---

## templates/ 职责

| 路径 | 用途 |
|------|------|
| `templates/harness/bootstrap/` | 最小 .harness 模板（5 分钟接入） |
| `templates/harness/standard/` | 标准 .harness 模板（30 分钟接入） |
| `templates/harness/standard/governance/` | 生命周期与质量门禁模板 |
| `templates/harness/enterprise/` | Enterprise 说明与清单 |
| `templates/harness/standard/harness.yaml` | harness.yaml 模板 |
| `templates/harness/standard/config/rule-id.yaml` | Rule ID 模板 |

---

## .harness/ 结构（Standard 实例）

```
.harness/
├── AGENTS.md              ← AI 入口
├── harness.yaml           ← 治理配置
├── rules/                 ← 标准维护规则
├── knowledge/             ← 仓库知识（架构、治理模型）
├── skills/skills.yaml     ← Skill 注册表（本库为空启用）
├── workspace/             ← AI 工作记录
├── context/layers.yaml    ← 上下文分层
├── config/
│   ├── paths.yaml         ← 路径常量
│   └── rule-id.yaml       ← Rule ID 注册表
└── governance/            ← 生命周期、门禁、exceptions
```

---

## 与消费项目的关系

本仓库不包含具体项目规则。消费项目通过以下方式接入：

1. 复制 `templates/harness/standard/` 到项目 `.harness/`
2. 编辑 `harness.yaml` 填写项目信息
3. 在 `.cursor/rules/` 等 Adapter 层引用 Rule ID
